# SSRI-unimi

Repository contenente esercizi, laboratori e progetti sviluppati durante il corso di laurea triennale in sicurezza dei sistemi e delle reti informatiche presso l'Università degli Studi di Milano.


## Contenuto

La repository è organizzata per insegnamento.
Ogni cartella principale contiene il materiale relativo al rispettivo corso e dispone di un file `README.md` con maggiori dettagli sulla struttura, sulle tecnologie utilizzate e sulle modalità di compilazione ed esecuzione dei progetti.

| Cartella | Descrizione |
|---|---|
| [`Algoritmi e strutture dati`](./Algoritmi%20e%20strutture%20dati/) | Esercizi in C |
| [`Programmazione/`](./Programmazione/) | Esercizi in C e Java + Progetto |
| [`Programmazione web e mobile/`](./Programmazione%20web%20e%20mobile/) | Esercizi per lo sviluppo web + Progetto |
| [`Statistica e analisi dei dati/`](./Statistica%20e%20analisi%20dei%20dati/) | Esercizi in python |



## Note

Il materiale presente nella repository è stato sviluppato a scopo didattico.
Le istruzioni specifiche per compilare, avviare o utilizzare ciascun esercizio o progetto sono disponibili nei README delle relative cartelle.
