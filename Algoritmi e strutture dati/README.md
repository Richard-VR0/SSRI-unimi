# Algoritmi e strutture dati (FAD004)

Questa cartella raccoglie esercizi e progetti svolti durante il corso di **Algoritmi e strutture dati**.


## Contenuto

La cartella è organizzata per lezioni: ogni sottocartella corrisponde a una lezione e contiene i relativi esercizi.

## Tecnologie utilizzate

| Linguaggio | Compilatore |
|---|---|
| C | gcc |


## Compilazione ed esecuzione

Dalla cartella della lezione:

```bash
> gcc nome_file.c -o nome_programma

> ./nome_programma
```


## Note

Gli esercizi e i progetti presenti in questa cartella sono stati sviluppati a scopo didattico per approfondire la progettazione e l'implementazione di algoritmi e strutture dati in linguaggio C.
